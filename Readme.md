# HR Recruitment Intelligence Platform

An HR analytics platform that brings recruitment data from different sources into one clean, connected system and turns it into clear hiring insights.

## Overview

Recruitment data is often spread across application records, interview results, offers, and joining information. This makes it difficult for HR teams to understand where candidates are dropping out and why.

This project brings that information together and presents it as a recruitment funnel, helping HR identify bottlenecks, drop-off points, and the reasons behind candidate loss.

## What the Platform Does

- Collects recruitment data from CSV/Excel files
- Validates and cleans uploaded data
- Standardizes inconsistent values such as department or role names
- Connects records to reconstruct each candidate's recruitment journey
- Calculates candidate counts and drop-off rates at each hiring stage
- Measures time spent at different recruitment stages
- Provides insights by department and role
- Breaks down candidate drop-off by reason
- Supports date-range filtering
- Displays the insights through an interactive dashboard

## Recruitment Funnel

The platform follows candidates through stages such as:

```text
Application
    ↓
Screening
    ↓
Interview
    ↓
Offer
    ↓
Joined
```
At each stage, the system helps identify how many candidates continue, how many drop out, and where the biggest bottlenecks occur.

## Key Insights

The dashboard is designed to answer questions such as:

- Where are we losing the most candidates?
- What is the drop-off rate at each stage?
- Which departments or roles have the biggest bottlenecks?
- How long do candidates spend at each stage?
- Why are candidates dropping out?
- How does recruitment performance change over time?

## Project Goal

The goal is to turn scattered recruitment data into **clean, reliable, and actionable hiring intelligence**, allowing HR teams to quickly understand problems in the recruitment process and make better decisions.

## Project Status

This project is being developed as an MVP focused on recruitment funnel analysis, data quality, and actionable HR insights.
